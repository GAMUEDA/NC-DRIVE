Parts only sit at 0° or 180° (or the whole nest at 90°/270°) to respect grain direction — never mixed. This is a laser, not a print, so nothing gets flipped/mirrored (etching would end up on the wrong side).
Forces every part the same way (grain is kept). Change it, then press Nest Parts again.
Full-length nests keep a clear lane at each 4' mark (a 10' sheet = 3 sections, a 14' sheet = 4) with a cut line drawn there, so the sheet can be cut into handleable pieces. If a part is longer than 4' that job isn't sectioned.
One straight cut across the usable width, 0.5" above the tallest placed part on each sheet — frees the unused sheet above the nest in one strip.

One-time setup — how do I get this address?
  1. One person makes a free account at dash.cloudflare.com (operators never need one).
  2. Workers & Pages → Create → Start with Hello World → Deploy, then Edit code.
  3. Delete what is there, press , paste it in, Deploy.
  4. Left menu: Storage & databases → KV → Create a namespace (any name).
  5. Back on the Worker: Settings → Bindings → Add → KV namespace, variable name KV, pick that namespace, Deploy.
  6. Paste the Worker’s address (ends in .workers.dev) above and press Use.
Photos pass through your own Worker for a few minutes (deleted as soon as the PC picks them up, or after 10 minutes) over HTTPS — nobody else’s server is involved.
